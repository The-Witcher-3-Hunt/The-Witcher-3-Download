## 🧠 Overview

The Witcher 3: Wild Hunt is a large-scale role-playing adventure set in a richly detailed fantasy world. You play as Geralt of Rivia, a seasoned monster hunter whose search for Ciri leads him through regions affected by war, political struggles, supernatural forces, and ancient mysteries.

The journey combines exploration, narrative quests, monster contracts, character progression, and real-time combat. Decisions made throughout the adventure can influence relationships, quests, and the direction of the story, giving optional activities an important place alongside the main campaign.

## 🚀 Key Features

| Feature               | Description                                                                              |
| --------------------- | ---------------------------------------------------------------------------------------- |

| Dynamic Combat        | Combine swordplay, dodging, blocking, counterattacks, Signs, and tactical preparation.   |

| Character Development | Unlock abilities and customize Geralt's combat and utility skills.                       |
| Alchemy               | Create potions, oils, and other useful preparations from collected ingredients.          |
| Equipment System      | Discover, craft, upgrade, and manage weapons and armor throughout the adventure.         |
| Side Adventures       | Encounter numerous optional quests and stories across the world.                         |
| Gwent                 | Challenge characters to matches of the collectible card game found throughout the world. |
| Story Expansions      | Continue the adventure with Hearts of Stone and Blood and Wine.                          |

## Additional Information for Windows Users

The game provides a broad selection of graphics options, allowing players to balance image quality and performance according to their hardware. Higher resolutions, advanced lighting, and enhanced visual effects can significantly increase GPU requirements.

For a stable experience, keep Windows and graphics drivers updated and adjust individual settings rather than relying exclusively on the highest preset. Keyboard and mouse controls as well as compatible gamepads are supported.
